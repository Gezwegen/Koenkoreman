Getting started / Local preview

1. Clone the repository

   git clone https://github.com/Gezwegen/Koenkoreman.git
   cd Koenkoreman

2. Open index.html in a browser or serve a static server:

   npx http-server .

Deploying to Netlify

1. Create a free Netlify account and connect your GitHub account.
2. Click "New site from Git" and select the Gezwegen/Koenkoreman repository.
3. Set the build command if you use a static site generator; otherwise leave blank. Set the publish directory to `public` or `/` depending on your project structure.
4. Deploy the site.
