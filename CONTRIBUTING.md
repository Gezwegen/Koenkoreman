# Contributing

Thanks for your interest in contributing to Koenkoreman! We welcome collaborators of all backgrounds.

Before you contribute

- Read the Code of Conduct: CODE_OF_CONDUCT.md
- Read the Privacy Policy: PRIVACY_POLICY.md

How to contribute

1. Fork the repository and create a branch for your change.
2. Open an issue describing the problem or feature first if it's not trivial.
3. Submit a pull request with a clear title and description.
4. Maintain style consistent with existing code (HTML, CSS, JS).

Issue templates and PR templates are provided to guide contributions.
