# How to apply for Netlify's Open Source plan (checklist)

This file helps you collect the information required by Netlify when requesting the Open Source plan and credits.

Required items before applying

- [x] Public repository with an OSI-compatible license (LICENSE included)
- [x] Contact email for maintainers: stefmaes0101@gmail.com
- [x] Code of Conduct file (CODE_OF_CONDUCT.md)
- [x] Privacy policy (PRIVACY_POLICY.md) or explanation of data collection
- [x] Live demo (deploy to Netlify and paste the Site URL)
- [x] Short project description in README.md

Suggested items to improve chances

- Issue / PR templates and CONTRIBUTING.md (included)
- Active recent commits and maintainer responsiveness
- Clear documentation and README with deployment instructions
